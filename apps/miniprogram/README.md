# 小程序壳（web-view）

这个目录是一个最小的微信小程序工程：只有一个页面，用 `web-view` 打开已部署的 H5 站点。
用户端的全部功能（浏览、登录、收藏、写作、问答、工作坊申请）都由 H5 提供，小程序不重复实现。

## 使用前提

- 小程序主体必须是企业、政府、媒体或其他组织（**个人主体不能使用 web-view**）。
- 站点域名已完成 ICP 备案，并使用 HTTPS。
- 在「小程序后台 → 开发管理 → 开发设置 → 业务域名」添加站点域名。添加时微信会要求下载一个校验文件，
  把它放到服务器的 `deploy/verify/` 目录（Nginx 会在站点根路径提供它），再点击保存。

## 步骤

1. 修改 `config.js` 中的 `SITE_URL` 为站点地址。
2. 在 `project.config.json` 中把 `appid` 改为小程序的 AppID。
3. 用微信开发者工具导入本目录，预览后上传，在小程序后台提交审核。

## 注意

- web-view 内不能打开未配置为业务域名的外部链接，所以 H5 在小程序中会把作品来源、图片版权链接显示为纯文本。
- 登录使用 H5 的邮箱账号与 Cookie 会话，在 web-view 内同样有效；暂未接入微信一键登录。
- 小程序审核对「教育」「社区/UGC」类目有资质要求（例如用户提交内容可能需要相关类目），提交审核前请按实际功能选择类目。
