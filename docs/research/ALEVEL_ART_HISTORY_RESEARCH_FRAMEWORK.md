# A-level 艺术史：商业机会研究框架

日期：2026-09-19。状态：**用户已确认研究范围，正文已形成[商业机会与执行方案](ALEVEL_ART_HISTORY_BUSINESS_RESEARCH.md)**。本页保留确认时的判断与修订过程，不代表市场缺口已经验证，也不是开发或招生授权。原始来源与核算保存在[研究底稿](../../ir_cache/alevel-art-history/STATUS.md)。

## 需要先讨论的三个判断

1. **决定成败的是能否持续找到有明确任务、愿意付费的学生，以及专业反馈能否稳定交付。** 界面吸引力与资料丰富度可以帮助获客，但不能代替这两项验证。[判断/中]
2. **值得测试一个小规模付费服务，现有证据不足以支持立即改造成完整 A-level 培训平台。** Pearson 最新英国地区统计显示，2026 年艺术史科目考生为 715 人；中国该科目的实际规模仍缺资料。[判断/中；来源 S02]
3. **首个产品候选是“看作品—提出论点—用证据写作—教师反馈—修改”的训练服务。** 对已经选修艺术史 A-level 的学生，它是备考辅导；对尚未选修该科目的申请者，它是能力训练。两类人必须分开招生、评价和算账。[判断/中；来源 S01、S04]

阅读标记：🟢事实为已核对的公开资料；🟠主张为机构或项目自述；🟡推导说明计算或推理；🔴判断为研究建议；⚪缺失为尚未得到的证据。颜色表示依据性质，不代表好坏；🔴判断不等于危险。

## 研究对象与边界

- 以**中国大陆及海外华语学习者**为主要商业对象；英国用于核对资格、供给、价格与教学方式。用户已确认此范围。
- 核心研究 Pearson Edexcel GCE A-level **History of Art（9HT0）**。它可在国际地区开设，但不能据此称为 Pearson International A Level 同一套资格。
- 分别比较 **Art & Design 实践课程、艺术史科目辅导、作品集与申请支持**，不混加考生与市场收入。
- 研究目的为 Common Room 下一阶段的业务选择；不做证券估值或融资材料，不给机构的宣传成绩背书。
- 公开资料可以核对考试、供给和标价；付费意愿、成交价、教师交付水平与中国招生规模需要访谈和实际试点。

### 规模与增长数据的限制

- **715 人**来自 Pearson 2026 年临时统计，封面明确 **UK Only**。它不是全球考生、两年全部在读学生或中国可获客人数。[官方统计](https://qualifications.pearson.com/content/dam/pdf/Support/Grade-statistics/A-level/grade-statistics-june-2026-provisional-advance-level.pdf)
- **838 人**可从 AAH 的 2025 年附表和 Pearson 2025 年搜索索引读到；后者原 PDF 地址直接访问返回 404。以这两个年度数字核算，2026 年减少 123 人、约 14.68%；这是带访问限制的年度比较，不能由一年变化推断长期消失。[AAH 原报告](https://courtauld.ac.uk/wp-content/uploads/2025/11/AAH-report-FINAL.pdf)、[计算底稿](../../ir_cache/alevel-art-history/calculations.md)
- AAH 正文称 2019–2025 年增长 42%，但自身附表的 483→838 按常规基期算法约为 73.50%。本次不采用 42% 宣传表述，也没有把尚未澄清的长期序列作为投资依据。[同一原报告](https://courtauld.ac.uk/wp-content/uploads/2025/11/AAH-report-FINAL.pdf)、[核算过程](../../ir_cache/alevel-art-history/calculations.md)

### 报名与经营条件也会改变业务选择

- **考试通路：** 中国的历史报名资料曾列 9HT0，当前一般考试页也有 GCE 服务信息；但尚未确认 2027 年具体城市是否接收该科目私人考生，以及费用与截止日。不能先售卖完整考试路径，再假定考点一定可用。[2023 年报名指南，第 13 页](https://www.britishcouncil.cn/sites/default/files/pearson_edexcel_exam_registration_guidance_may_june_2023.pdf)、[当前中国考试服务](https://www.britishcouncil.cn/exams/school/pearson)
- **收费教学：** 深圳市教育局 2026-07-10 告知书涉及办学许可、收费与面向中小学生的培训广告要求。艺术史 A-level 在具体课程、年龄、线上或跨境交付中的适用类别仍需确认；不能因名称含“艺术”就自行认定豁免。正式试点需明确授课主体和适用规则，或评估具备相应条件的合作方。[主管部门原文](https://szeb.sz.gov.cn/home/jyxw/jyxw/content/post_12887672.html)
- **教学可信度：** 当前项目的 Essay Room 使用本地规则分数，没有独立教师校准或考试评分对应关系。作者的样课与批改能力需要用真实任务验证。[现有实现](../ARCHITECTURE.md#状态保存与学习流程)

## 建议的正式报告结构

以下为章节问题与暂定结论，均可被后续证据推翻。

| 章节 | 要回答的问题 | 暂定结论／待验证判断 🔴 |
| --- | --- | --- |
| 1. 这门生意服务谁 | 学生、家长、教师、学校分别买什么？ | 付费理由应围绕具体学习和交付任务建立。 |
| 2. 课程与考试到底是什么 | 艺术史、艺术设计和作品集的考核、报名和升学作用有何不同？ | 考试局、科目代码、选修主题和考点可用性必须先明确。 |
| 3. 市场有多大，缺口在哪里 | 英国规模与趋势；中国能核实到什么程度？ | 英国存在供给分布不均；中国商业缺口尚待验证，不能直接移植。 |
| 4. 已有供给怎么收费和交付 | 公益课、完整网课、双语辅导、个人教师、学校各自解决什么？ | “有中文、有 AI、有资料”不足以单独形成优势。 |
| 5. 比较三条业务路径 | 科目辅导、能力短课、学校／教师合作，哪条适合先做？ | 优先检验有限范围的专业反馈服务，再决定是否扩科或做机构工具。 |
| 6. 每招一个学生是否赚钱 | 学费如何覆盖教学、批改、获客、技术与管理时间？ | 创作者的时间必须计成本；软件降低重复工作，不自动消除教学成本。 |
| 7. Common Room 需要补什么 | 当前功能距离可靠教学交付还有哪些差距？ | 持久保存、作业版本、教师反馈、课程映射与评价可信度，比扩大馆藏更靠前。 |
| 8. 怎样验证与决定继续／停止 | 如何找人、试教、定价测试，什么结果值得继续？ | 先核实真实选课、教师交付、考试与经营条件，再检验购买；不预设市场缺口成立。 |

## 必须解释的三组矛盾

1. **学校供给少，但考生总量也小。** 地域上的不易获得课程，可能与学校开班不经济同时存在；不能只解释其中一面。
2. **学校不要求该科目，但要求相近能力。** 资格辅导与能力训练可能共享材料，却有不同的购买理由、评价标准与竞争者。
3. **希望更多人使用，但人工反馈容量有限。** 免费博物馆可以扩大入口；收费服务必须限定教师时间、提交次数和交付内容。两者是否相互促进需要实际转化证据。

## 决定业务选择的追问

| 问题 | 当前工作答案 |
| --- | --- |
| 靠什么赚钱？ | 尚无收入；候选为限期训练与人工反馈，不把现有网站当作已成立的订阅生意。 |
| 处于价值链哪一段？ | 学习与反馈；考试资格由考试局和考点决定，录取由学校决定。 |
| AI 会怎样改变它？ | 可辅助解释和练习；对事实、视觉分析和评分的可信度仍需验证。不能用现有规则分数冒充考试评价。 |
| 谁会挑战它？ | 完整网课、教师辅导、学校原有课程、免费资源，以及通用 AI。 |
| 优势是否可复制？ | 场景和界面可以复制；可靠教学、细分课程匹配和获客关系需要单独证明。 |
| 存量与新增需求各有多大？ | 英国考生数据已找到；中国考生与愿意额外付费的人数未知。 |
| 价值可能被谁拿走？ | 若只是资料与聊天，容易成为他人课程中的一个功能；若能稳定改善写作，教师服务可能有独立价值。 |
| 换到中国是否成立？ | 双语教学、考试安排、支付与教学服务边界需逐项验证；英国数据不能直接外推。 |
| 最强反方是什么？ | 科目太小、已有替代、招生分散、批改费时，作者可能没有对应考纲的教学记录。 |
| 什么团队适合做？ | 能提供经核验的艺术史教学与写作反馈，并能接触目标学生的团队；作者的具体能力仍需样课检验。 |
| 当前建议最可能错在哪里？ | 错把评论区少量专业需求当成可持续招生渠道，或低估现有教师已经满足的需求。 |
