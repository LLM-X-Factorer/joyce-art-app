# 主题课短视频：写稿与画面指南

2026-10-04 根据三路调研整理：中文艺术 / 知识类短视频创作者、英文优秀艺术视频的叙事方法、纪录片与视频随笔的画面强调手法，以及第 01 课的史实核对。第 01 课「现代性」的第一版稿子被认为「AI 味重、圈注单调」，本指南就是为了解决这两个问题。

## 一、第一版的问题

| 问题 | 第一版的例子 | 为什么不好 |
| --- | --- | --- |
| 抽象开场、预告式元话语 | 「什么时候，艺术开始变得现代？今天用三件作品……」 | 前 3 秒最值钱，却没有任何能看的东西；没人真的会问这个问题 |
| 结论代替证据 | 「诚实地面对自己的时代」「明确的社会身份」 | 大词无法配画面，也无法被验证 |
| 套路化排比 | 「谁在观看，谁在付钱，谁被看见，谁被忽略」 | 典型的 AI 节奏；排比最多一处，且要在情绪到位之后 |
| 每件作品同一模板 | 先看 → 背景 → 意义 | 节奏单调；60–90 秒只能讲透一件事 |
| 旁白复述画面 | 「再看女仆、花束和那只黑猫」 | 画面已经给了，旁白应该补画面给不了的信息 |
| 强调手法单一 | 每个细节都画一个圈 | 不同内容需要不同的观看方式 |

## 二、写稿原则

1. **第一句给一个能看见的东西或一个反常识的点**，不给概念，不做自我介绍和预告。
   - 吕宸：「如果去卢浮宫只能看一幅画，我不推荐《蒙娜丽莎》，而是看这幅。」
   - Great Art Explained：「On the 8th May 1889, Vincent Van Gogh was admitted to a mental asylum…」
2. **一条视频只讲一件事**；每件作品只讲一个最锋利的点。何老师在发呆：「讲的要少……你给观众一个火种，然后让观众自己燃烧它。」
3. **带观众的眼睛走**：用指令句加方位词（「先别看人，往右下角看」），说法与镜头运动同时落下。
4. **旁白补画面没有的**：时间、数字、人物、当时的反应、对比。不要「画面是牛，旁白说牛」（PBS 制片人 Jon Else）。
5. **用当时人的一句原话做证据**：评论、抗议信、画家书信。一句就够，必须能查到出处。
6. **把大师当普通人，平视**（杨藩：「不要神化任何人，大师也是人」）：缺钱、被骂、自我怀疑都可以讲，但要有依据。
7. **身份、阶层、观念落到一个具体的人、物或动作上**：不说「社会身份」，说「她换掉了提香画里的那只狗」。
8. **短句，补主语，口头连接词**（「可」「只不过」「后来」），写完念出来改；能少一个字就少一个字。
9. **排比最多一次，放在结尾情绪到位时**，且用具体名词（「被骂的裸女，被骂的铁塔……」），不用抽象名词。
10. **可以坦白不确定**：「有一种说法是……」「我们不知道她姓什么」。不确定的轶事要么标注，要么不用。
11. **结尾回到画面或给一个能回答的问题**，不喊口号、不总结大词。小红书偏收藏与讨论，适合留一个问题。
12. **作者本人的感受可以加**：Joyce 录音时可以在合适位置加一句自己的真实感受（例如第一次看到原作的反应），但不要替作者编造经历。

节奏参考：前 6 秒内要有钩子，之后每 10–15 秒给一个新细节或新信息（ABC 对 TikTok 艺术史博主 Mary McGillivray 的报道转述）。

## 三、画面强调手法（按内容选，同一手法不要连续出现）

模板已支持的手法（`apps/video/template/player.js`，分镜里写在 `scene.emphasis`）：

| 手法 | 写法 | 适合的内容 | 不适合 |
| --- | --- | --- | --- |
| 聚光 | `spotlight` | 单个小细节：眼神、手、一颗星 | 细节本身很暗或面积很大 |
| 局部放大卡 | `inset` | 远处的小细节、另一件作品的对照局部（如提香维纳斯的脸） | 细节与整体关系才是重点时 |
| 上下对比 | 场景 `compare` | 来源与影响（提香 ↔ 马奈）、同题材两个版本 | 比例差异很大的两件作品 |
| 描线 | `trace` | 视线方向、构图对角线、笔触走势 | 构图松散时硬画线 |
| 取色 | `swatch` | 讲色彩关系（蓝与黄、黑与白） | 与色彩无关的段落 |
| 数字 | `stat` | 尺度、工程、数量（18,038 个铁件） | 信息密集段落 |
| 年份印章 | `year` | 交代时间节点 | 连续多段都用 |
| 引文卡 | `quote` 场景 + `quote` | 接受史、争议、画家书信 | 查不到出处的引文 |
| 圈注 | `ring` | 只用于「位置」类信息 | 作为默认手法 |
| 镜头推拉 | 每个场景的 `camera` | 所有场景的基础运动 | — |

尚未实现、以后可加：实景或地图对照（例如圣雷米窗景与画面）、擦除对比、抠像隔离、人形尺寸对比、时间轴条。

内容类型 → 推荐手法：

| 内容 | 主选 | 备选 |
| --- | --- | --- |
| 单个细节 / 象征物 | 局部放大卡、聚光 | — |
| 视线 / 构图 | 描线 | 聚光 |
| 色彩 | 取色 | — |
| 来源 / 影响 | 上下对比 | 局部放大卡 |
| 观察与想象的差异 | 局部放大卡 | 实景对照（待实现） |
| 争议 / 接受史 | 引文卡 | 数字 |
| 尺度 / 工程 | 数字 | 人形对比（待实现） |
| 时间节点 | 年份印章 | — |

## 四、配音

默认使用 Seed Audio 1.0 的「甜妹学霸」参考音色（与 CS 基础课一致；用法见 `apps/video/README.md`）。写稿时注意：

- 文字会经过平台审核，避免「裸」等敏感字眼；艺术语境下改用「那幅画」「她」等说法（小红书、视频号的审核同理）。
- 引号「」只影响字幕显示，不影响朗读。
- 数字按中文习惯写（「1865年」「一万八千多个」），合成会自然读出。
