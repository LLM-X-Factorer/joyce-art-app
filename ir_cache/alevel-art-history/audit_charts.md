| 首期总成本 | 16,200 | 原始运算“六人首期总经济成本”：10,200 + 6,000 | 一致 |

检查结果：

1. 纵轴从 0 到 20,000，等额 5,000 刻度对应等距 66 像素，未截轴、未使用隐性对数。
2. 三柱共享底线 y=316，柱高按数值线性换算；几何误差仅为 SVG 一位小数的正常舍入。
3. 图标题标明“方案假设”，正文替代文本标明“全部为方案假设”，图注说明每人 2,480 元、劳动时间已计入、税与机构分成未计；全部柱使用斜纹，不会把假设混作实测。
4. 同图使用相同样式表示同一类假设，横轴名称明确区分收入、重复交付成本、首期总成本，未把三项错误叠加成收入构成。
5. 图在单一主方案中展示收入相对于两类成本的位置；正文价格表则比较三种价格的余量，二者比较问题不同，没有重复绘制两张同内容图。
6. 本次报告仅一张数据图，但数据有限且任务属于专项商业研究，没有为了图数制造无源趋势图或市场规模图。图数本身不构成缺陷。

## 数字复核方法

读取 `unit_economics_operations.json` 的 90 条 `stdin` 与 `stdout`，以 Python `Decimal` 独立执行 `product`、`ratio`、`sum_check`、`diff_check`，逐项比较记录结果及退出码；90 / 90 一致。另以 XML 解析图中柱高、底线、数字标签，逐一对照 JSON 主方案与首期总成本计算；3 / 3 一致。复核未重跑会写回底稿的生成脚本，未修改输入文件。

## 表格和结构化表达

- 第 3 章将英国 2026 年 `UK Only / Total Sat / provisional`、2025 年访问限制、开课机构数和中国未知人数分开；未将考生等同培训买家，也未将考试中心等同课程提供者。
- 第 4 章明示价格为核查当日页面展示，保留英镑；列出课程时长、导师支持、促销、考试费和免费项目资格差异，没有伪装成同质产品的性价比排名。
- 第 5 章将三条业务路径放入同一表格，比较购买任务、决策者、困难和优先次序；服务卡的次数、周期、班额与定价均标为方案假设。
- 第 6 章人民币、人数、工时、费率及缺失成本均显式说明；三种定价和三种单变量敏感性分别呈现，未添加不成立的情景概率或利润率。首期与重复开班有独立列，机会成本未被说成现金支出或净利润。
- 第 7—8 章通过功能行为／完成依据、开班前产物／责任／条件、复盘决策／记录／行动表表达执行关系。每章均可定位核心判断，不触发 C11 的连续两章结构化表达缺席。
